Troostwijk searches

Troostwijk blocks automated visitors, so the bot never visits it. These links open Troostwijk's own search for your watchlist in the Netherlands. Save each search on Troostwijk and forward their alert emails to your alerts mailbox: the lots in those emails then appear here with a price and max bid (see README).

How the numbers work

You pay = bid + buyer's premium, plus VAT on both, plus any fixed fee per lot, plus the drive to the pickup address if you count it.

Resale = Marktplaats median asking price × your sell percentage, × the number of items for lots like “2 x …”. Exact model compares listings of the same type number; ≈ Rough price means the lot title has no type number, so it's compared with similar items. Asking prices are not sold prices.

Margin = resale − what you pay, and as a % of what you pay.

Bids are from the morning scan. Always check the live bid, the lot description, pickup date and the auction terms before bidding.

Keep favorites on GitHub

Favorites are saved in your auction-deals repository, so they show on all your devices and the bot can remind you in Telegram before they close. That needs a key (token) that can only edit issues of that repository. You do this once per device.

  1. Create the token on GitHub ↗. The name, 1-year expiry and the permission Issues: Read and write are filled in for you.
  2. Under Repository access, choose Only select repositories and pick auction-deals.
  3. Click Generate token, copy it and paste it here.

The token is stored only in this browser and can't change your code or settings.
